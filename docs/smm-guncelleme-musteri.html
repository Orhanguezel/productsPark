SMM Otomatik Link Sistemi Tamamlandi

Hazirlayan: Gelistirme Ekibi  |  Tarih: 19 Mart 2026  |  Surum: 1.0

1. Mevcut Sorun Neydi?

Sorun SMM urunleri icin musteri linki sistem tarafindan otomatik istenmiyordu. Admin her urun icin iki ayri sekmeye gidip manuel ayar yapmak zorundaydi. Bu adim unutulduğunda musteri link girmeden siparis olusturuyordu ve teslimat basarisiz oluyordu.

Eski akis:

  1. Teslimat sekmesi → delivery_type = API, saglayici ve servis ID sec
  2. Ozellestirme sekmesi → ayrica manuel olarak type = URL custom field ekle
  3. Ikinci adim unutulursa musteri hic input gormuyor, link olmadan siparis olusturuluyor, teslimat basarisiz oluyor

2. Ne Yapildi?

Cozum Urun ve kategoriye "SMM Urunu / SMM Kategorisi" anahtari eklendi. Bu anahtar acikken musteriden sosyal medya profil linki otomatik olarak isteniyor. Admin'in ayrica custom field tanimlamasina gerek kalmadi.

Admin Paneli — Urun Formu

Teslimat Ayarlari sekmesinde, API teslimati secildiginde yeni bir toggle goruntuleniyor:

Yeni toggle — Admin paneli / Teslimat Ayarlari sekmesi
SMM Urunu [ ACIK ]
Aciksa musteriden sosyal medya profil linki otomatik istenir.

Admin Paneli — Kategori Formu

Kategori duzenleme sayfasinda da ayni toggle eklendi. Kategoriyi SMM olarak isaretleyince o kategorideki tum API urunleri otomatik link ister — her urun icin ayri ayri acmaya gerek kalmaz.

Musteri Urun Sayfasi

SMM Urunu acik olan bir urune girildiginde, custom field tanimi olmasa bile asagidaki input otomatik goruntuleniyor:

Musteri sayfasinda gorunen alan Sosyal Medya Profil Linki *
Hizmetin uygulanacagi profilin tam linkini girin. (ornek: https://instagram.com/kullanici_adi)
  • Alan zorunlu — bos birakilirsa sepete eklenemiyor
  • Gecerli URL formati kontrol ediliyor (https:// ile baslamali)
  • Hatali girilirse uyari mesaji gosteriliyor

4. Admin Kullanim Kilavuzu

Yeni SMM urunu nasil tanimlanir?

  1. Admin panel → Urunler → Yeni Urun (veya mevcut urunu duzenle)
  2. Teslimat Ayarlari sekmesine gec
  3. Teslimat Tipi: API Entegrasyonu sec
  4. API saglayici sec (ornegin: smmget.com)
  5. Service ID gir (SMM panelindeki servis numarasi)
  6. SMM Urunu toggle'ini acik konuma getir
  7. Kaydet
Sonuc Musteri bu urune girdiginde sosyal medya link alanini gorur. Baska hicbir ayar yapmana gerek yok.

Bir kategorinin tamamini SMM olarak isaretlemek icin:

  1. Admin panel → Kategoriler → Ilgili kategoriyi duzenle
  2. SMM Kategorisi toggle'ini acik konuma getir
  3. Kaydet

Bu kategoriye bagli olan tum API urunleri artik musteri link isteyecek.

6. Canli Sunucu Icin Yapilmasi Gerekenler

Onemli: Canlı veritabanı yeniden kurulmadıysa asagidaki SQL sorgularini MySQL konsolunda calistirmaniz gerekmektedir. Bu islem tek seferlik olup mevcut verileri etkilemez. 
-- products tablosuna is_smm kolonu ekle
ALTER TABLE `products`
  ADD COLUMN `is_smm` TINYINT(1) NOT NULL DEFAULT 0
  COMMENT 'SMM urunu: musteriden otomatik sosyal medya linki alinir';

-- categories tablosuna is_smm kolonu ekle
ALTER TABLE `categories`
  ADD COLUMN `is_smm` TINYINT(1) NOT NULL DEFAULT 0
  COMMENT 'SMM kategorisi: bu kategorideki API urunleri otomatik link alir';
Not Kolon zaten varsa "Duplicate column name" hatasini alirsiniz — bu durumda ALTER calistirmaniza gerek yok, sistem zaten guncel demektir.

SQL'i calistirdiktan sonra ek bir isleme gerek yoktur. Frontend ve backend kodlari yeni deploy ile birlikte aktive olur.
